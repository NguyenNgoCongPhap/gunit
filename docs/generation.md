# Generated information-size twin

Rust struct-core-units owns quantity declarations and conversion metadata. Its wire-codegen emit_gleam output is copied byte-for-byte into the module declared in unit-twin.toml; the generated JSON catalog comes from the same published commit. No local producer checkout, TypeScript implementation, FFI or hand-written conversion table is used.

Set REPO_SEED to an absolute reviewed repo-seed checkout containing coordinator/process.py, seed/scripts/tiered_gate.py, scripts/sync_agents_block.py and shared/agents/library-family.md. The gate uses that reviewed process owner for Git-context isolation, redacted diagnostics and four-attempt Git fetch/ls-remote retries with bounded backoff. It never assumes a sibling checkout. Missing owner tools refuse before spawning a child.

Use Python 3.15, Gleam and the committed dependency manifest. Run `py -3.15 scripts/unit_twin.py --write` after the producer's dependency-ordered wave merge. The manifest follows the producer's actual default branch; unit-twin.lock.json records resolved commit, blob IDs and SHA-256 output digests. The writer also derives the contract's factor facts from actual generated Gleam guards, checks them against the producer metadata and regenerates the browsable catalog index. Contract prose remains hand-authored.

Run `py -3.15 scripts/check.py` for the canonical gate. It checks the shared instruction block, current published producer and exact generated bytes, all Gleam tests, repository-wide formatting/lint/types, catalog coverage and the whole Python control suite. `--library-rules-only` is a narrow preflight and makes no full-gate claim. This repository has no tracked commit hook that calls the gate or fetches dependencies.

Both generated files, code-derived factor claims and the index have drift controls. Schema, path, symlink, stale-head and mid-collection producer changes refuse explicitly. The native JavaScript target is exercised through Gleam tests and a real compiled consumer checking nonfinite construction and decoding. Python controls use disposable copies; no persistent test mutates tracked generated files. The coordinator owns the one clean exact-head standing gate before merge.

The library version stays frozen. Consumers use its default branch and commit the resolved lock; products relock once after the library wave. No package publication, tag, release, deployment or application adoption is part of this change.
